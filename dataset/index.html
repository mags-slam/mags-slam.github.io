Overview

Existing multi-agent SLAM benchmarks force a trade-off between photometric realism, agent count, and ground-truth completeness. Real-world sets provide authentic sensor noise but no dense mesh ground truth and no semantic supervision, while synthetic sets built on Replica cap the team at two agents.

ReplicaMultiAgent Plus re-renders Replica scenes through Habitat-Sim with up to four human-teleoperated agents per scene. Each trajectory is driven by an operator at 30 Hz with a game controller, mixing long forward sweeps, look-arounds, brief stops, and revisits, while following a per-scene overlap budget. The benchmark simultaneously provides:

  • Larger robot teams with long trajectories: four agents per benchmark scene, up to 3,049 frames and 39.2 m per agent.
  • Controlled inter-agent overlap, ranging from largely disjoint to heavily co-visible multi-agent splits.
  • Dense ground truth: metric depth, camera poses of all agents in one shared world frame, and a dense mesh per scene.
  • Semantics: per-pixel Replica semantic labels for every frame.

It supports the evaluation of monocular, RGB-D, and semantic multi-agent SLAM for collaborative dense reconstruction.

Data Format

Every archive contains one folder per agent (part1 … partN = agent 1 … agent N). All agents of a scene are recorded in the same world frame.

Apart-0/
├── apart_0_part1/            # agent 1
│   ├── rgb/                  # 000000.png, 000001.png, ...
│   ├── depth/
│   ├── semantic/
│   ├── groundtruth.txt
│   └── intrinsics.txt
├── apart_0_part2/            # agent 2
├── apart_0_part3/            # agent 3
├── apart_0_part4/            # agent 4
└── tsdf_mesh_w0.0.ply        # ground-truth mesh (four-agent scenes)
FileContent
rgb/NNNNNN.png8-bit RGB image, 640 × 480.
depth/NNNNNN.png16-bit PNG, metric depth in millimetres (divide by 1000 for metres).
semantic/NNNNNN.png16-bit PNG, per-pixel Replica semantic class ID.
groundtruth.txtCamera poses in TUM format, one line per frame: timestamp tx ty tz qx qy qz qw (camera-to-world, 30 Hz). Line i corresponds to image i. Poses follow Habitat's OpenGL camera convention (x right, y up, z backward).
intrinsics.txtfx fy cx cy width height = 320 320 320 240 640 480 (pinhole, 90° horizontal FoV, identical for all agents).
tsdf_mesh_w0.0.plyDense ground-truth mesh of the scene (four-agent scenes).

Loading one frame in Python:

import numpy as np
from PIL import Image
from scipy.spatial.transform import Rotation

seq = "Apart-0/apart_0_part1"                       # Apartment-0, agent 1
fx, fy, cx, cy, W, H = np.loadtxt(f"{seq}/intrinsics.txt")
poses = np.loadtxt(f"{seq}/groundtruth.txt")        # t tx ty tz qx qy qz qw

i = 0
rgb = np.array(Image.open(f"{seq}/rgb/{i:06d}.png"))
depth = np.array(Image.open(f"{seq}/depth/{i:06d}.png")) / 1000.0   # metres
semantic = np.array(Image.open(f"{seq}/semantic/{i:06d}.png"))     # class IDs

c2w = np.eye(4)
c2w[:3, :3] = Rotation.from_quat(poses[i, 4:8]).as_matrix()
c2w[:3, 3] = poses[i, 1:4]
c2w_opencv = c2w @ np.diag([1, -1, -1, 1])           # OpenGL -> OpenCV camera axes
